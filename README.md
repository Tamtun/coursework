# Инвестиционная система с Flask и Pandas

## Описание

Этот проект представляет собой веб-приложение на базе **Flask**, которое позволяет загружать и анализировать транзакции из файла Excel. Приложение предоставляет API для поиска транзакций, фильтрации данных и получения информации об инвестициях, связанных с различными пользователями. Также используется **Pandas** для обработки данных.


## Установка и настройка

Для запуска проекта на локальной машине, выполните следующие шаги:

1. **Клонировать репозиторий**:

git clone https://github.com/yourusername/investkopilka.git cd investkopilka


2. **Создать и активировать виртуальное окружение**:

Для Windows:
python -m venv venv .\venv\Scripts\activate

Для macOS/Linux:
python3 -m venv venv source venv/bin/activate


3. **Установить зависимости**:
pip install -r requirements.txt


4. **Настроить файл данных**:

Убедитесь, что файл `data/operations.xlsx` существует и имеет нужный формат (с колонками "Дата операции", "Сумма операции", "Описание", "Категория").

5. **Запуск приложения**:

Запустите Flask-приложение:
python app.py


Приложение будет доступно по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## API

### 1. `/api/investkopilka`

**Метод**: `GET`

**Описание**: Получение инвестиционных данных на основе месяца.

**Параметры**:
- `month` (обязательный): месяц в формате `YYYY-MM` (например, `2023-05`).
- `limit` (необязательный): лимит на количество транзакций (по умолчанию 100).

**Пример запроса**:
http://127.0.0.1:5000/api/investkopilka?month=2023-05&limit=50

**Ответ**:
{ "total": [ /* Данные о инвестициях */ ] }

### 2. `/api/search/phone`

**Метод**: `GET`

**Описание**: Поиск транзакций, связанных с телефонами.

**Пример запроса**:
GET http://127.0.0.1:5000/api/search/phone

**Ответ**:
[ { "Дата операции": "2023-05-01", "Описание": "Пополнение баланса телефона", "Сумма операции": "1000", "Категория": "Телефония" }, ... ]

### 3. `/api/search/person`

**Метод**: `GET`

**Описание**: Поиск транзакций, связанных с определёнными людьми.

**Пример запроса**:
GET http://127.0.0.1:5000/api/search/person
